GPU-Accelerated CFD Optimization at Petrobras

Mechanical Engineering InternPetrobrasJun 2025 – Aug 2025Florianópolis, Brazil

Petrobras runs lattice-Boltzmann (LBM) computational fluid dynamics simulations on NVIDIA GPUs to model complex flows. My internship: make the solver faster. Using AI-assisted, kernel-level profiling in NVIDIA Nsight Compute, I attacked the code's memory and precision bottlenecks one by one — and the result was one of the fastest LBM implementations reported anywhere.

Precision migration — the 400% win

The solver ran everything in FP64 double precision. I led a validated FP64→FP32 migration — proving accuracy stayed within simulation tolerances at every step — which unlocked 400%+ gains in MLUPs (million lattice updates per second), the standard LBM throughput metric.

Memory-access surgery

Nsight Compute memory-workload reports revealed severely uncoalesced global memory access. Restructuring the thread-to-data mapping delivered a 60% warp-efficiency improvement. I also identified redundant data staging in shared memory and enabled aggressive reuse across thread blocks, cutting peak shared memory 35% (56 KB → 36 KB) and improving occupancy.

Smarter meshes in Python

I authored a Python geometry-generation script for optimized fine-coarse mesh interfaces, lifting the peak simulated Reynolds number 33% without degrading throughput — more turbulent, more realistic flows for the same compute budget.
