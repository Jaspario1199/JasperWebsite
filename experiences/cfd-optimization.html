CUDA CFD Research Internship

Mechanical Engineering Intern  |  Petrobras · Geoenergia Lab, UDESC  |  Jun 2025 – Aug 2025  |  Santa Catarina, Brazil

I spent the summer at the Geoenergia Lab in Santa Catarina State University's petroleum engineering department, working on Petrobras-sponsored research. The lab runs lattice Boltzmann (LBM) fluid simulations on NVIDIA GPUs, and my job was to make the solver faster.

The Lattice Boltzmann Method, Briefly

Instead of solving the Navier-Stokes equations directly, LBM tracks particle distribution functions on a lattice through alternating collision and streaming steps. Each lattice site updates independently, which is exactly the kind of problem a GPU is built for.

Finding the Bottleneck

The lab's higher-order physics code was running about 10x slower than expected, and neither refactoring nor manual timers explained why. The breakthrough came from kernel-level profiling in NVIDIA Nsight Compute: the source view revealed lingering double-precision FMA instructions in hot loops. Removing them and completing a validated FP64 to FP32 migration (accuracy checked against simulation tolerances at every step) produced 400%+ gains in MLUPs, the standard LBM throughput metric, with the higher-order kernels improving by roughly 500%.

Memory Work

Nsight's memory workload reports also showed severely uncoalesced global memory access causing long scoreboard stalls. Restructuring the thread-to-data mapping improved warp efficiency by 60%. Enabling aggressive data reuse across thread blocks cut peak shared memory from 56 KB to 36 KB, which raised occupancy on the same hardware.

Grid Refinement

Flows near boundary conditions were producing unstable results, so we moved to a multiresolution grid: fine lattice at the boundaries, coarse in the middle. I wrote the Python script that generates optimized fine-coarse interface geometries, which lifted the peak simulated Reynolds number by 33% without hurting throughput.

Passing It On

Profiling knowledge shouldn't leave with the intern, so I wrote an Nsight Compute manual and recorded an instructional video for the lab covering setup, best practices, and common commands. I also built ParaView post-processing scripts and prototyped a stair-step curved boundary method for extending 2D cylinder flows to 3D spheres.
