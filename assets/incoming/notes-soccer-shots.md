# Soccer Shots / "Table Soccer" — project notes (MEEN 210, Spring 2025)

Source: MEEN 210 Milestone 4 deck. **Do not use the PDF's images** — Jasper is
sending the specific photos he wants. This file is context for writing the page.

- **Course / team:** MEEN 210 (Spring 2025), Group 24 — Thomas Erb, Daniel Crain,
  Jasper Buntinx, Andy Geldmacher. Product name in the deck: **"Table Soccer."**
- **Target user & need:** elderly couples, especially former athletes. Goals:
  reconnect them with their athletic/competitive past, improve dexterity & fine
  motor control (grip + spring resistance), create a shared two-player activity
  to strengthen bonds / reduce loneliness, and stay cheap + simple.
- **How it plays:** one player uses a **spring-loaded shooting mechanism (launcher)**
  to fire a ball; the other controls a **pivoting goalie** to block. Two separate
  assemblies: the **goal + goalie** and the **launcher**.
- **Design process:** concept generation → grouping/criteria down-select →
  engineering (handle sized for many hand sizes, sub-assembly tolerances for smooth
  sliding) → modeling from part drawings → fabrication.
- **Fabrication:** almost entirely **3D-printed PLA**.
  - Goal side, handle, goalie, sides → Creality K1; connecting rod → Creality K1 Max;
    goal back/base → Voron 2.4.
  - Launcher front/handle → Creality K1 Max; back/base + end caps → Creality K1
    (holes enlarged + end-cap depth increased after first test).
  - **Sourced parts:** interchangeable springs (Home Depot), suction-cup feet (Amazon).
  - Budget: stayed under the credit limit; ~$43 on accessories.
- **Challenges:** dimensional fit + print failures — end caps not fitting the handle,
  handle not seating in the launcher back; had to sand parts to size; printer failed
  multiple times; suction cups weak; springs shorter than expected.
- **Successes:** pole/hole tolerancing in the shooting mechanism (accuracy);
  a smooth **pivot point** under the goalie for easy blocking; deciding **not** to
  build a fixed field — lets users play on any tabletop at any distance (versatile).
- **Future work:** tune handle/back diameters for fit; size guide rods to a chosen
  spring length/stiffness/diameter; better-sourced suction cups; a **rotating base**
  for the launcher; print the goal as one piece instead of hot-gluing for stability.

**Framing for the portfolio:** this is a user-centered, design-for-manufacture
mechanical project — real customer discovery, tolerance/fit engineering on sliding
components, spring mechanics, DFM tradeoffs on an all-3D-printed assembly, and an
honest iteration story (fit failures → sanding/redesign → functional product).
